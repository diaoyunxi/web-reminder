## Configuration Options

| Setting | Description | Default |
|---------|-------------|---------|
| Enable Notifications | Turn notifications on/off | ✅ On |
| Sound | Play sound with notifications | ✅ On |
| Require Interaction | Keep notification visible until clicked | ❌ Off |
