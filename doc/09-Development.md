## Development

### Generate Icons
```bash
cd icons
python3 generate_icons.py
```

### Debugging
1. Go to `chrome://extensions/`
2. Find "Web UI Change Detector"
3. Click "Inspect views: background page" to debug background script
4. Open DevTools on any webpage to debug content script
